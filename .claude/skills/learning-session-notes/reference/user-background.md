## Full-stack course — coding-academy.org (completed)

A 4-sprint full-stack bootcamp, syllabus: coding-academy.org/pdf/syllabus.pdf (pages 16-18).

- **Sprint 1 — Coding Games:** computers/networks and HTTP basics, JavaScript fundamentals (variables, logic, functions, loops, arrays, objects), algorithmic thinking, HTML/CSS, the DOM rendering model, recursion, data structures and complexity.
- **Sprint 2 — Responsive mobile-first applications:** advanced HTML/CSS (Grid, Flexbox), Git/GitHub collaboration, graphical design and pixel-perfect implementation, responsive/mobile-first design, media queries, advanced DOM manipulation, touch events, MVC architecture.
- **Sprint 3 — Single Page Applications:** modern JS and modules, async/Promises, AJAX, React (components, composition, routing, lifecycle hooks, error boundaries, reactivity, event bus, server communication), Redux state management, performance/memory considerations.
- **Sprint 4 — Frontends and Backends:** Node.js server-side logic, REST APIs, authentication/authorization, WebSockets, MySQL and MongoDB (relational and non-relational), data modeling, cloud deployment, Vite, offline-first PWAs.
- **Extra workshops:** secure coding, advanced TypeScript, Angular, Vue, backend deep-dive, testing/automation, intro to Docker/DevOps, clean code and design patterns, functional vs. OOP, PHP, Python.

So the learner has hands-on, project-driven exposure to the full web stack (vanilla JS through React/Redux, Node/Express-style backends, both relational and document databases, and a Docker/DevOps taste), not just theory.

## How to apply

- Don't over-explain fundamentals this background already covers: basic networking, OS-level memory/disk/process concepts, general backend architecture and protocols, database internals, Docker/Kubernetes mechanics, Git, full-stack web development end to end (JS/React through Node/SQL/MongoDB).
- Do go deep on mechanism-level detail for anything specific to the new tool/topic being learned (e.g. Elasticsearch's shard allocation, inverted indexes, cluster coordination) — this learner absorbs depth quickly and prefers it over a slow ramp through basics they already have.
- Plain language is about clarity, not about cutting technical content — see this skill's own "Simplify language, never content" rule.
